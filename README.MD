# Discord 炸群機器人


## 📌 專案說明
本專案為一個 Discord Bot 範例，用於展示在高權限情況下，
Discord API 可能造成的嚴重影響行為，例如：

- 頻道與角色管理操作
- 成員管理行為
- Webhook 與事件觸發機制

## 🧩 技術環境
- Python 3.x
- Discord API
- 使用套件：
  - `py-cord`
